# Compact text summary of enrichment results for the AI prompt

Compact text summary of enrichment results for the AI prompt

## Usage

``` r
summarize_enrich_for_ai(enrich, n_terms = 15)
```

## Arguments

- enrich:

  an enrichment result list (`method`, `table`) as produced by the
  Enrichment tab, or NULL

- n_terms:

  max terms to list

## Value

a character string, or NULL when no usable results are supplied
