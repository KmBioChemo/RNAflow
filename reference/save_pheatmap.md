# Save a pheatmap to disk

Save a pheatmap to disk

## Usage

``` r
save_pheatmap(ph, file, fmt = c("pdf", "png", "tiff"), w = 8, h = 8, dpi = 300)
```

## Arguments

- ph:

  a pheatmap object

- file:

  output path

- fmt:

  "pdf", "png" or "tiff"

- w, h:

  dimensions in inches

- dpi:

  resolution
