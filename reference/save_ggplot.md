# Save a ggplot to disk

Save a ggplot to disk

## Usage

``` r
save_ggplot(p, file, fmt = c("pdf", "png", "tiff"), w = 8, h = 6, dpi = 300)
```

## Arguments

- p:

  a ggplot object

- file:

  output path

- fmt:

  "pdf", "png" or "tiff"

- w, h:

  dimensions in inches

- dpi:

  resolution (used for PNG/TIFF)
