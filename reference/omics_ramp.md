# Continuous "omics" color ramp

Perceptually-uniform ramp from scico when available, else viridis.

## Usage

``` r
omics_ramp(palette = "batlow", n = 256)
```

## Arguments

- palette:

  scico palette name (e.g. "vik" diverging, "batlow" sequential, "roma",
  "lajolla", "bam")

- n:

  number of colors

## Value

a character vector of hex colors
