# Synchronized slider + numeric input pair

Useful for fine control when a slider alone is too coarse.

## Usage

``` r
ui_slider_num(slider_id, num_id, lbl, mn, mx, val, stp)
```

## Arguments

- slider_id:

  slider input ID

- num_id:

  numeric input ID

- lbl:

  label

- mn, mx:

  min/max

- val:

  initial value

- stp:

  step

## Value

a UI element
