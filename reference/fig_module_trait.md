# Module-trait correlation heatmap

Module-trait correlation heatmap

## Usage

``` r
fig_module_trait(mt, mode = c("exploration", "publication"), text_size = 2.6)
```

## Arguments

- mt:

  the list returned by
  [`module_trait_cor()`](https://KmBioChemo.github.io/RNAflow/reference/module_trait_cor.md)

- mode:

  "exploration" or "publication"

- text_size:

  size of the in-cell r / p labels

## Value

a ggplot2 object
