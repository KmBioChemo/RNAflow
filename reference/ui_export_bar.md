# Export toolbar (format + dimensions + download button)

Export toolbar (format + dimensions + download button)

## Usage

``` r
ui_export_bar(prefix, def_w, def_h)
```

## Arguments

- prefix:

  prefix used to build input IDs (`<prefix>_fmt`, `_w`, `_h`, `_dpi`,
  `_dl`)

- def_w, def_h:

  default dimensions (inches)

## Value

a UI element
